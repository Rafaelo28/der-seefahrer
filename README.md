# Der Seefahrer

Ein Seefahrer-Abenteuer für den Browser (gemacht für das iPad), Nachfolger von
[Gamble Klicker](https://rafaelo28.github.io/Gamble-Klicker/). Port Dublone wurde ausgeraubt, die Goldene Dublone ist weg
und das alte Geld nichts mehr wert – jetzt zählt Bernstein. Segle über die Seekarte, handle in Häfen und finde den Dieb.

**Spielen:** https://rafaelo28.github.io/der-seefahrer/

- Der Spielstand aus Gamble Klicker kann übernommen werden (automatisch im selben Browser oder per Export-Code).
  Gamble Klicker selbst bleibt dabei unverändert.
- Reines HTML, CSS und JavaScript – `index.html` im Browser öffnen genügt.
- Alles ist Spielgeld, es gibt keine Käufe mit echtem Geld.

Plan und Ausbaustufen: [PROJEKTPLAN.md](PROJEKTPLAN.md) · Regeln für die Entwicklung: [CLAUDE.md](CLAUDE.md)

Tests: `node tests/run-all.js` und `node tests/browser.test.js` (Playwright).

Ein Spiel von [Rafaelo28](https://github.com/Rafaelo28).
